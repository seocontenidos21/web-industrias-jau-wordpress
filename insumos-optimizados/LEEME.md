# Imágenes optimizadas

Aquí van las imágenes del cliente **ya optimizadas** (WebP, nombres sin espacios), generadas con:

```bash
python -I herramientas/optimizar-imagenes.py
```

- Los originales (hasta 40 MB) van en `insumos-originales/` y **no** se suben al repo.
- `manifiesto.json` lista cada original, su versión optimizada, tamaño y uso.
